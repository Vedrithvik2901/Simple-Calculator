# Calculator App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

## Features

* Basic arithmetic operations (+, −, ×, ÷)
* Clean and modern UI
* Responsive layout
* Real-time input display

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```
calculator-app/
│── caluclator.html
│── calculator.css
│── calculator.js
```

## How to Run

1. Download or clone the repository
2. Open `calculator.html` in your browser

## Future Improvements

* Keyboard support
